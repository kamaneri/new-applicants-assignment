## ⚠️ Common Problems

### Problem: File saves as .txt instead of .cs

**Solution:**
1. When saving, change "Save as type" to **"All Files (*.*)"**
2. Manually type the filename as: `TradeManagerPanel.cs`
3. Make sure it doesn't become `TradeManagerPanel.cs.txt`

### Problem: Windows hides file extensions

**Solution:**
1. Open File Explorer
2. Click "View" tab
3. Check "File name extensions" box
4. Now you can see the real extension

### Problem: File won't open in NinjaTrader

**Solution:**
1. Make sure the file is truly a .cs file (not .txt)
2. Make sure you're importing as **Add-On**, not Indicator
3. See [HOW_TO_USE.md](HOW_TO_USE.md) for import instructions
